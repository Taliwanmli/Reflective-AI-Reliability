# Security and privacy reporting

## Supported scope

This repository currently contains documentation, synthetic examples, JSON Schemas, and an offline Python validator. It does not contain a deployed service, production application, credentials, or model-provider integration.

## Reporting a concern

Do not open a public issue for a suspected secret, personal-data exposure, private-source disclosure, or exploitable vulnerability. Use GitHub's private vulnerability-reporting channel for this repository if it is available. If no private channel is available, contact the repository owner through a private GitHub channel without including sensitive payloads in the first message.

Include the affected path, impact, reproduction steps, and a minimal non-sensitive proof. Do not access unrelated data or test against systems outside this repository.

## Research-data incidents

Real reflections and personal data are prohibited. If such material is accidentally committed, stop redistributing it and report it privately. Removing a file in a later commit is not sufficient because Git history may retain it; the maintainer will assess history rewriting and downstream copies case by case.

No bounty, response time, or disclosure deadline is promised.
